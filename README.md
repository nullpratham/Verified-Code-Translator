# Verified Code Translator

Team: forked.exe · Course: SCSE4041 · Problem: C7 · Direction: C++ → Python.

A two-stage human-in-the-loop workflow. Stage 1 generates a translation prompt. The user runs it in ChatGPT and pastes the Python candidate into Stage 2. Stage 2 generates a separate static-review prompt.

## Run locally
Open `index.html` in a modern browser. No dependencies or server are required.

## Scope
This is a prompt-generation prototype. It does not call an AI API, execute code, or formally prove equivalence. ChatGPT interaction is manual. Test execution was not performed in this package; no test results are claimed.
